## 👩‍💻 About Me

I'm a recent B.Tech graduate in Artificial Intelligence and Machine Learning who enjoys taking a model all the way from messy raw data to something people can actually use. That means cleaning data, engineering features, training and comparing models, and then shipping them as live apps.

## 🚀 Featured Projects

### 📄 [DocBot: AI Document Q&A Chatbot (RAG)](https://github.com/shruti041/docbot) · [Live Demo](https://shruti-docbot.streamlit.app/)
Ask questions about any uploaded PDF. Answers come only from the document, with source passages shown, and "not found" instead of guessing.
- Hybrid retrieval: semantic search + BM25 + section-reference lookup
- Voice input and spoken answers in English and Hindi
- Deployed on Streamlit Cloud with rate limits and SHA-256 caching

`Python` `LangChain` `Gemini API` `Hugging Face` `BM25` `Streamlit`

### 🎵 [Music Genre Classification](https://github.com/shruti041/Music-Genre-Classification)
Deep neural network on MFCC audio features, **89% validation accuracy**, with real-time genre prediction on uploaded audio.

`Python` `TensorFlow/Keras` `NumPy` `Streamlit`

### 👥 [HR Analytics: Employee Attrition Prediction](https://github.com/shruti041/Employee_attrition_prediction)
End-to-end ML pipeline. Gradient Boosting reached **89.12% accuracy**, served in a Streamlit app with probability scores, Plotly charts, and retention recommendations.

`Python` `Pandas` `Scikit-learn` `Plotly` `Streamlit`
